# Учёт археологических экспедиций

Курсовой проект на C# и MariaDB. Приложение Windows Forms позволяет просматривать и добавлять записи об экспедициях, объектах раскопок, находках, специалистах и расходах. Доступ к разделам зависит от роли вошедшего пользователя.

## Запуск

Требуются Windows, .NET 8 SDK и локальный сервер MariaDB. Создайте пустую базу `arch_exp` с кодировкой `utf8mb4`, затем выполните [database/schema.sql](database/schema.sql) в этой базе. Схема восстановлена по пояснительной записке. Для проверки интерфейса можно выполнить [database/demo.sql](database/demo.sql) в той же базе и войти под демонстрационной учётной записью `demo_admin` с паролем `local-demo-only`.

Из корня репозитория:

```powershell
$env:ARCH_EXP_CONNECTION_STRING = 'Server=127.0.0.1;Port=3306;Database=arch_exp;User ID=app_user;Password=replace-me;'
dotnet run --project arch_exp/arch_exp.csproj
```

В строке подключения укажите учётные данные своей локальной БД. Или откройте `arch_exp.sln` в Visual Studio с компонентом Windows Forms, запущенной с той же переменной среды. Исходный учебный экран входа сравнивает пароль с данными в БД в открытом виде. Используйте локальные демонстрационные данные и отдельный пароль.
